\section{Conclusion}

This paper introduced Script2Layout, a framework for manga layout generation from scripts, and constructed Manga109Script, the first large-scale dataset for this task. Experiments showed that script conditioning improves performance over existing methods across multiple metrics. Limitations include that script cues did not always yield gains under strong constraint conditions and that our LLM-based approach incurs higher computational cost, resulting in slower generation compared to diffusion-based baselines. Future work includes combining size and script cues, exploring stronger base models, and assessing practical implementations. Beyond manga, these advances could contribute more broadly to story-to-visual content generation and narrative visualization applications.
