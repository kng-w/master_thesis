\section{Related Work}
\subsection{Layout Generation}
Layouts crucially impact viewers' comprehension and perception of visual content. The pursuit of excellent layouts across various media has driven research in layout generation models \cite{shi_intelligent_2023,shi_understanding_2023,huang_survey_2023}. Previous research primarily targets layouts emphasizing element visibility, such as mobile UIs~\cite{deka_rico_2017,jiang_coarse--fine_2022}, posters~\cite{seol_posterllama_2024,yang_posterllava_2024,tanaka_scipostlayout_2024, advertising_posters}, and PDFs~\cite{zhong_publaynet_2019,jiang_coarse--fine_2022}. 

To meet the demands of practical applications and diverse design workflows, various constraint-based generation approaches have been developed. These approaches include generation conditioned solely on element types~\cite{lee2020neural,jiang_layoutformer_2023}, on both element types and size specifications~\cite{jiang_layoutformer_2023,kong2022blt}, and relational constraints between elements~\cite{lee2020neural,kikuchi_constrained_2021}. There are also interactive variations, such as layout completion that infers missing elements from partial layouts~\cite{gupta2021layouttransformer}, and layout refinement that improves existing layouts~\cite{rahman2021ruite}. Layout generation with fixed background images as a condition is called content-aware layout generation, which considers harmony with the background~\cite{RetrievalAugmentedLayoutTransformer2024,seol_posterllama_2024}.

Model development under these various constraints has enabled more accurate layout generation.
Layout generation models have evolved from early GANs~\cite{li_layoutgan_2019} and VAEs~\cite{arroyo_variational_2021, jyothi2021layoutvaestochasticscenelayout} to Transformers~\cite{jiang_layoutformer_2023} and diffusion models~\cite{inoue2023layoutdm, zhang_layoutdiffusion_2023,Chen_2024_WACV}. Recent studies have also explored the use of LLMs for this task~\cite{lin_layoutprompter_2023,tanaka_scipostlayout_2024}.

Despite these technical advancements, generating layout from narrative context is still unexplored. This challenge arises from dataset scarcity and the difficulty of converting narrative dynamics into visual layouts. Modern LLMs are now capable of interpreting complex contexts and nuances effectively~\cite{LLMunderstandingNarrative}. 
Leveraging these capabilities, we propose Script2Layout, a task to generate layouts directly from scripts. We evaluate our approach against state-of-the-art methods such as LayoutDM~\cite{inoue2023layoutdm}, LayoutFormer++\cite{jiang_layoutformer_2023}, and LayoutPrompter~\cite{lin_layoutprompter_2023}, thereby demonstrating both its effectiveness and innovative potential.

\subsection{Manga Understanding as Visual Storytelling}
High-quality script data is essential for the Script2Layout task, and its construction requires advanced techniques for narrative extraction from images.

Visual storytelling, the task of generating narratives from image sequences, was pioneered by Huang~\cite{huang_visual_2016}. The field evolved from early models using Convolutional Neural Network (CNN) and Recurrent Neural Network (RNN)~\cite{yu2017hierarchicallyattentivernnalbumsummarization} to later methods using hierarchical attention~\cite{nahian_hierarchical_2019}, scene graphs~\cite{wang_storytelling_scenegraphs2020}, and causal reasoning~\cite{song2024causalstorylocalcausalattention}. These techniques move beyond simple image recognition to capture inter-image relationships and ensure narrative coherence.

Recent advances in VLLMs like GPT-4o~\cite{wu_gpt-4o_2024} and Gemini~\cite{team_gemini_2024} have enhanced detailed context extraction from images, creating new opportunities in Visual Storytelling~\cite{yang_storyllava_2025}.
However, applying VLLMs to manga reduces performance due to a domain gap from its distinctive visual language, \eg, black-and-white art, unique reading orders, and discrete time and space within panels.
These distinctive features make manga understanding a complex task composed of multiple intertwined subtasks. As illustrated in the CoMix benchmark~\cite{vivoli_comicspap_2025}, these include panel segmentation, dialogue ordering, and character re-identification across panels~\cite{sachdeva_manga_2024}. Character re-identification is particularly challenging, with GPT-4 achieving less than 50\% accuracy~\cite{vivoli_comicspap_2025}.

To circumvent these challenges, we leverage solutions to key subtasks, providing the model with pre-processed inputs like ordered dialogue with speaker attribution~\cite{li_manga109dialog_2024} and annotated character regions~\cite{shtedritski_what_2023}. This design allows the model to bypass low-level visual parsing and focus on generating high-quality narrative scripts, leveraging its core vision-language capabilities.

While datasets like Manga109Story~\cite{chen_manga_2024} provide prose narratives, our primary aim is a {\it script-format} dataset. Accordingly, we developed Manga109Script with professional creators to fit conventional manga production workflows.
