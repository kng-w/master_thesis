# Introduction

適切なレイアウトは視覚情報の効果的な伝達において不可欠である。要素の配置は、閲覧者の注意や理解を導き、作品全体の印象を決定づける重要な役割を果たす。この原理は、多くの視覚表現に適用されるが、とりわけ漫画という表現形式においては、物語の伝わり方を左右する作品の核として独自の意義をもつ。

物語を伝える表現には、文字を主体とする小説や映像を描くアニメまで、多岐にわたる形式が存在する。中でも漫画は、平面をコマへと分割し、その中にキャラクターやセリフを配置する固有の表現形式をもつ。一般的な漫画の制作過程において、このようなレイアウトはネームと呼ばれる下書きの中で決定される。脚本やプロットに基づき、より効果的な物語の魅せ方として工夫されるコマの大きさやキャラクターの位置関係といった漫画のレイアウトは、作品の演出として漫画の魅力を高める重要な役割を担っている[]。

レイアウトを生成するモデルの研究は、これまで アプリケーションUI やポスターなど、主として正確な情報伝達を担う機能的なレイアウトを対象に発展してきた[]。一方、漫画におけるレイアウトのように、物語の展開に連動する演出的なレイアウトの研究は、これまで十分に行われてきていない。その一因に物語とレイアウト情報が結びついたデータの不足が挙げられる。

しかしながら、近年大規模視覚言語モデル（Vision-Language Large Model, VLLM）の発展により、画像から高精度に言語情報を抽出することができるようになり []、漫画のような複雑な視覚表現に対しても、物語情報の抽出が現実的なものとなってきた［］。

そこで本研究では、VLLMを活用し、日本の商業漫画作品を集積したデータセットManga109 []をもとに、計  19,555ページに対応した脚本データセットManga109Scriptを作成した。ここで作成した脚本は、場所を示す柱、人物の動作や情景を描写するト書き、人物のセリフを要素として含む、日本において一般に用いられる脚本のフォーマット[] に準拠している。作成した脚本の品質については、複数の基準を設け実施した人手による評価によりその妥当性を確認した。

さらに、Manga109Scriptを活用することで、脚本を直接の入力とする漫画レイアウト生成モデルを、複数の大規模言語モデル（LLM）をベースモデルに開発した。従来のレイアウト生成手法との比較実験および脚本の有無による性能評価を網羅的に実施した結果、脚本の活用が生成される漫画レイアウトの品質向上に寄与することが確認された。本研究は、脚本に基づくレイアウト生成という新たな課題Script2Layoutに対し、有力なベースラインを提供する。

我々の貢献は以下の通りである：

1. 漫画約2万ページに対応する脚本データセットManga109Scriptを構築したこと
2. 脚本を直接の入力とする漫画レイアウト生成モデルを複数のLLMで開発し、その有効性を検証することで、脚本に基づくレイアウト生成という新たな課題Script2Layoutのベースラインを確立したこと

# Related Work
## Layout Generation
レイアウト生成の研究は、これまで、Webデザインやバナー広告、ポスター、プレゼンテーションスライド、雑誌の表紙、アプリケーションユーザーインターフェースなど、さまざまな視覚表現を対象に発展してきた[]。これらの表現において重視されるのは、情報の階層性を明確にし、視認性と情報伝達の効率性を最大化するレイアウトである。

このような要求に応えるため、具体的なユースケースをもとに、多様な制約に基づく生成技術が提案されている。レイアウト要素のカテゴリーを既知として制約とする手法[]、要素のカテゴリーと大きさの両方を既知として制約とする手法[]、要素間の相対的な位置関係を指定する手法[]、一部の要素を与え残りを補完する手法[Gupta et al., 2021]など、実際のデザインワークフローに応じた多様なニーズに応える制約付き生成手法が提案されている。

レイアウト生成モデルの進化は、これらの制約を効果的に取り扱うことを可能にしている。敵対的生成ネットワーク（GAN）[]や変分オートエンコーダ（VAE）[]を活用するモデルからTransformerをベースとしたモデル[]、双方向モデル[]へと発展し、さらには、個別拡散モデルを応用したLayoutDM[Inoue et al., 2023]なども登場している。このようなレイアウト生成モデルの変遷は、複数の異なる制約条件を単一のアーキテクチャで汎用的に扱うことを可能にし、レイアウトの生成精度を向上させている。

さまざまな制約を取り扱う技術が進歩している一方、物語の文脈情報を制約にするレイアウトの生成はこれまで十分に取り組まれてきていない。これは、この課題が物語から抽出される抽象的な概念（緊張感や感情の高まり、場面転換の重要度など）を、コマの大きさや配置といった具体的な視覚表現へと変換する高度な物語情報の意味理解と表現変換を必要とする複雑な問題であることに起因する。しかし近年のLLMはその急速な技術革新により、物語の複雑な文脈理解ついても性能を向上させている []。そこで本研究では、LLMをベースモデルとして活用することで、脚本に基づくレイアウト生成モデル、Script2Layoutモデルの開発に取り組んだ。

## Manga Understanding as Visualstorytelling
脚本に基づき漫画レイアウトを生成する課題への取り組みは、漫画画像に対応する高品質な脚本データの存在は不可欠であり、その構築には画像から物語情報を抽出する高度な技術が求められる。

一連の画像から物語を生成・認識する研究課題はVisual Storytelling[]と呼ばれる。これは Huangらの先駆的な研究[]を契機に発展してきた。初期の手法では、画像シーケンスの入力に対し、CNNによる特徴量抽出とRNNによる連続性の認識を活用する手法が中心に扱われてきた[]。階層的注意機構の導入[]、シーングラフを用いた意味構造のモデリング[]、因果関係の抽出に焦点を当てた手法[]などの拡張をみせ、画像から意味のある物語構造を抽出する様々な手法が提案されている。これらの研究は、単なる画像認識を超え、画像間の関係性や物語の一貫性など画像内における意味構造の捉え方に焦点を当てている。

近年は、GPT-4o[]やGemini[]など、VLLM（Visual Large Language Model）が急速に性能を高めており、画像内に含まれる複雑な文脈をより高精度に捉えられるようになってきた[]。これにより、Visual Storytelling に新たな可能性がもたらされている[]。

一方で、漫画画像の認識は、その特殊な表現形式ゆえに依然として高い難易度を持つ。漫画画像は主に白黒で描かれ、読み進める順は独自のルールがあり、分割されたコマそれぞれの中には時間・空間が離散的に表現される複雑な構造を持つ。Vivoliらの研究[]によれば、GPT-4でさえ、漫画内のキャラクター認識精度は50%にも満たないことが報告されている。漫画画像の認識は、コマの検出、セリフ領域の認識と順序の整理、キャラクターの識別など、高度なタスクが複合的に関わる問題である。漫画画像の認識を行う研究では、それぞれの課題が個別に取り組まれ、様々な手法が提案されている。

Ogawaら[]は、漫画のコマを自動的に検出し、その読み順を決定するモデルを提案し、Fujimotoら[]は、漫画特有の多様なフォントや配置を持つテキスト領域を正確に検出・認識する手法を提案した。キャラクター認識に焦点を当てた研究では、Yangら[]が、漫画キャラクターの姿勢や外見の大きな変化にも対応できる識別モデルを提案した。さらに、Sachdevaら[]は、セリフと発話者の関係を特定したうえで、セリフの読む順を決定するモデル Magna Whisper を提案した。

本研究では、漫画画像の認識が複数の困難なサブタスク（コマ検出、セリフ認識、キャラクター識別など）にまたがるという構造的課題を踏まえ、あらかじめ抽出されたそれらの情報を入力として活用し、発展著しい VLLM の能力を、漫画画像に対応する脚本生成器として最大限活用する工夫を施した。漫画画像に紐づく物語データセットには、ら[]の提案するManga109Storyも存在する。これは、それぞれの漫画に対応した物語を散文として備えるデータセットである。一方、本研究では、プロのクリエイターへのヒアリングを通じ、実際の漫画の制作プロセスの中で活用され得る脚本形式のテキストデータセットを構築した。

# Manga109Script
Manga109Script は、Manga109[] に収録された19,555ページの漫画画像に対応する脚本データセットである。Manga109[]は、日本の商業漫画109作品の漫画画像および漫画上におけるコマ、キャラクター、セリフの位置情報などを収録したデータセットである。適正な利用を条件に学術研究目的のため著作者の許諾のもとで公開されている。Manga109Script の構築では、Manga109に含まれる見開き単位のレイアウト情報をページ単位に整形し、それぞれのページに対応する脚本データを生成した。脚本の形式は日本で一般に用いられているフォーマットに従い、行頭に「◯」を付け記述される場所を表す柱、行頭から3文字分インデントを空け記述される人物や情景の描写であるト書き、行頭にキャラクター名を記しその直後の鍵括弧の中に記述されるセリフの3要素から構成される。日本のフォーマットに準拠するよう整備したのは、本研究において対象としている漫画が、日本の文化として発展しており、その制作過程において有益であるモデルの開発を念頭に置いているためである。

## Data Construction
Manga109Script の構築は、Manga109に含まれる漫画画像に、キャラクターの識別のためそれぞれの顔を異なる色の円で囲う visual prompting 処理[]を施し、処理した画像を1ページずつGPT-4oに以下の手順で与えることで行った。

GPT-4oとの対話は、脚本生成の対象とする1ページを基準に以下の3種に分けられる。
\begin{enumerate}[label=(\alph*)]
\item 初期理解の誘導: 対象ページを含む1話分のセリフをすべて与え、「物語を理解できたか」と問い、これに対して「ハイ」という返答がなされたことにする恣意的に作成した対話
\item 脚本生成: 対象ページの漫画画像、セリフ情報、あらすじ（対話タイプ(c)で作成）、脚本フォーマット等の説明を与え、脚本を生成させる対話
\item あらすじ生成: 対象ページに至るまでの漫画の内容をあらすじとしてまとめさせる対話
\end{enumerate}

これらの対話を「(a)→1ページ前の(b)→対象ページの(b)」と連結して脚本を生成し、「(a)→1ページ前の(b)→対象ページの(b)→(c)」と連結してあらすじを生成する。この一連の対話パターンを対象ページを順に変えながら実行することでManga109Scriptを構築した。

## Characteristics
Manga109Scriptの統計情報は以下の通りである。脚本要素の1ページあたりの平均数は、柱が1.38、ト書きが7.04、セリフが7.10であり、平均文字数は342.8字である。これらの要素に対応するレイアウト要素（Manga109に含まれるデータ）は、（描画ごとに区別した）キャラクター数が平均8.07/ページ（最大468、最小0、中央値7）、セリフ数が平均7.49/ページ（最大36、最小0、中央値7）、コマ数が平均5.31/ページ（最大20、最小1、中央値5）となっている

## Quality Evaluation
作成した脚本は短文のキャプションとは異なり特殊な形式を持つため、一般に用いられている画像キャプションの評価基準を適用することは難しい。そこで本研究では、人手による評価を行い、脚本の品質を確認した。

評価項目は以下の5つである：
\begin{enumerate}
\item 柱Recall: 漫画に描かれた場所が脚本の柱として記述されているか否かを正誤で判定
\item 柱Precision: 脚本の柱に記述された場所が漫画に描かれているか否かを正誤で判定
\item ト書きPrecision: 対象ページのト書きと他ページのト書きを混合したリストから、対象ページのト書きを正しく識別できるか判定
\item 文脈外ト書き検知精度: 同様のリストから他ページのト書きを正しく識別できるか判定
\item セリフRecall: 漫画に描かれたセリフが正確に脚本内に記述されているか否かを判定
\end{enumerate}

評価は、物語のつながりが理解できるよう、各作品から連続する約10ページを無作為に抽出し、合計1000ページを対象に行った。1000ページの脚本を500ページずつ分け、6名の評価者がそれぞれ500ページを担当することで、1ページあたり3名の評価が得られる構成とした。

評価結果は以下の通り、柱Recallが0.793、柱Precisionが0.838、ト書きPrecisionが0.664、文脈外ト書き検知精度が0.910、セリフRecallが0.988であることが確認された。
